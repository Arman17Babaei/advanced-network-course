# Activity Materials

This directory contains the detailed materials for the learning activities defined in [design/04_ACTIVITIES.md](../../design/04_ACTIVITIES.md).

Create one subdirectory or Markdown file per concrete activity. Each activity should document, as applicable:

- **Statement** — what students are asked to do.
- **Learning outcomes** — which course outcomes the activity prepares students for.
- **Methodology** — sequence, timing, group structure, facilitation, and required resources.
- **AI use** — whether AI is required, allowed, encouraged, or intentionally excluded, and why.
- **Expected learning process** — what reasoning, experimentation, discussion, or practice students should engage in.
- **Instructor / TA guidance** — how the activity should be run and where students are likely to need help.
- **Connection to assessment** — which later assessment evidence the activity prepares students to produce.
- **Supporting resources** — readings, examples, starter code, worksheets, datasets, prompts, or other materials.

Current activity families to detail include:

- non-submitted foundations practice assignments;
- modern networking concept and technology exposure;
- AI-assisted project-relevant paper study;
- project architecture and design work;
- experimental systems work;
- AI-agent onboarding and project use;
- technical reporting and presentation preparation.
