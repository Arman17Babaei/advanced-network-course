# Assessment Materials

This directory contains the detailed materials for the assessments defined in [design/03_ASSESSMENTS.md](../../design/03_ASSESSMENTS.md).

Create one subdirectory or Markdown file per concrete assessment. Each assessment should document, as applicable:

- **Statement** — what students are told and what evidence they must produce.
- **Learning outcomes** — which course outcomes are being assessed and at what Bloom depth.
- **Methodology** — timing, format, logistics, allowed resources, AI policy, and how the assessment is conducted.
- **Rubric** — explicit grading criteria and performance levels.
- **Evaluation procedure** — how the teaching team applies the rubric consistently and efficiently.
- **Individual vs. team evidence** — what can legitimately be inferred about individual students versus the team.
- **Reproducibility / verification** — scripts, test cases, expected evidence, or other mechanisms needed to verify results.
- **Supporting resources** — question pools, starter files, datasets, presentation guidance, or other assessment-specific material.

Supporting planning material:

- [Project Idea Pool](PROJECT_IDEA_POOL.md) — application-oriented project areas, recent-paper activity, and references for developing concrete project briefs.

Current assessment types to detail include:

- quizzes;
- midterm exam;
- bi-weekly project discussions;
- completed team project;
- 75-minute project presentation;
- final exam.
